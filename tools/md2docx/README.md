# md2docx — Markdown → .docx по ГОСТ 7.32 / 2.105

Оформление: A4, поля 30/10/20/25 мм, Times New Roman 14, интервал 1,5, абзацный отступ 1,25 см, выравнивание по ширине, автоперенос, номер страницы внизу по центру (на титульном не печатается). Таблицы — 12 pt, одинарный интервал, шапка повторяется на новых страницах. Листинги — Courier New 10.

```bash
pip install python-docx pyyaml
python tools/md2docx/md2docx.py labs/lab02/report.md -o labs/lab02/out/lab02.docx          # kind/lab/topic из фронтматтера
python tools/md2docx/md2docx.py coursework/pz/_pz.md -o coursework/out/pz.docx --kind pz
```

Титульный лист берёт данные из `reports/meta.yaml` (ищется вверх по дереву от исходника).

## Синтаксис

| Запись | Результат |
|---|---|
| фронтматтер `---` с `kind: lab\|pz\|plain`, `lab: 2`, `topic: "…"` | тип документа и титульный лист |
| `# ВВЕДЕНИЕ` (уровень 1 без номера) | структурный заголовок: по центру, прописными; в ПЗ — с новой страницы |
| `# ПРИЛОЖЕНИЕ А // Руководство пользователя` | две строки по центру; нумерация рисунков/таблиц внутри — «А.1» |
| `# 1 Описание …`, `## 1.1 …`, `### 2 Пункт` | заголовок с абзацного отступа, полужирный; номера пишутся вручную |
| `## Задание` (уровень 2+ без номера) | полужирный заголовок с абзацного отступа |
| `- пункт` / `1. пункт`, вложенность — 2 пробела | «– пункт» / «1) пункт» / «а) пункт» |
| `Таблица: Название {#tab:key}` строкой перед pipe-таблицей | «Таблица N — Название» над таблицей |
| `Листинг: Название {#lst:key}` перед блоком кода | «Листинг N — Название» |
| `![Название](screenshots/x.png){#fig:key}` | рисунок по центру + «Рисунок N — Название» под ним; нет файла → жёлтая заглушка «ВСТАВИТЬ СКРИНШОТ» |
| `[@fig:key]`, `[@tab:key]`, `[@lst:key]` | номер объекта («на рисунке [@fig:er]» → «на рисунке 3»); неизвестная ссылка подсвечивается |
| `**жирный**`, `*курсив*`, `` `код` `` | инлайн-форматирование |
| `\newpage` | разрыв страницы |
| `[[TOC]]` | поле «СОДЕРЖАНИЕ» — в Word выделить и нажать F9 |
| `<!-- комментарий -->` | не попадает в документ |

Пути к рисункам — относительно файла `.md`. Нумерация сквозная; ссылка должна стоять в тексте до объекта (ГОСТ).

## Проверка результата

```bash
soffice --headless --convert-to pdf labs/lab02/out/lab02.docx --outdir labs/lab02/out
```
Затем просмотреть PDF: заглушки скриншотов, подписи, нумерация страниц. Оглавление в LibreOffice/Word обновить вручную.
