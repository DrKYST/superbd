Пояснительная записка содержит {{PAGES}} с., {{FIGURES}} рис., {{TABLES}} табл., {{SOURCES}} источников, {{APPENDICES}} прил.

Объект разработки — учёт услуг связи, оказываемых фирмами-провайдерами Internet: провайдеры, общий реестр абонентов, договоры, сеансы связи и тарифы.

Цель работы — создание клиент-серверной информационной системы, в которой хранение данных, проверка ограничений, расчёты, отчёты и разграничение доступа выполняются средствами СУБД PostgreSQL, а настольное приложение служит тонким клиентом.

В процессе работы построена концептуальная модель предметной области в третьей нормальной форме, создана база данных с доменами, индексами и последовательностями, заполненная псевдослучайными данными, таблицы сеансов и договоров секционированы, разработаны представления и функции схемы api для запросов на выборку всех основных видов — соединений, итоговых запросов, объединения и запросов с подзапросами, реализованы пять групп пользователей средствами PostgreSQL, ограничение видимости строк по провайдеру пользователя и сброс пароля с временным паролем. Разработано клиентское приложение на Qt 6, которое строит интерфейс по группе пользователя, выводит списки постранично, показывает отчёты с диаграммами и сохраняет их в Excel. Корректность серверной части подтверждена набором из 140 автоматических тестов.

Использованные средства: PostgreSQL 18, PL/pgSQL, pgAdmin 4, Qt 6, C++17, CMake, Qt Charts, QXlsx.

СУБД POSTGRESQL, КЛИЕНТ-СЕРВЕР, РЕЛЯЦИОННАЯ МОДЕЛЬ, НОРМАЛИЗАЦИЯ, РОЛИ, РАЗГРАНИЧЕНИЕ ДОСТУПА, ХРАНИМЫЕ ФУНКЦИИ, ПРЕДСТАВЛЕНИЯ, QT, ИНТЕРНЕТ-ПРОВАЙДЕР
