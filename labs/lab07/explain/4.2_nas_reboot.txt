Запрос 4.2_nas_reboot (04_jsonpath.sql)
Раздел задания: jsonpath: @? с фильтром по элементам массива
Зачем: Инженер оценивает аварии: сеансы, оборванные перезагрузкой узла доступа (событие stop с причиной nas_reboot), — по узлам: сколько сеансов задело и когда последний раз

-- SQL
SELECT doc #>> '{source,nas,name}'           AS nas,
       doc #>> '{source,nas,vendor}'         AS vendor,
       count(*)                              AS sessions,
       max((doc #>> '{session,stopped_at}')::timestamptz) AS last_reboot
FROM lab7.session_record
WHERE doc @? '$.events[*] ? (@.type == "stop" && @.cause == "nas_reboot")'
GROUP BY 1, 2
ORDER BY 3 DESC, 1
LIMIT 10;
