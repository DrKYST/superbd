# Лабораторные работы

Одна папка на лабу: `lab01` … `lab08`.

```
labNN/
  README.md        что сделано, где файлы, СПИСОК СКРИНШОТОВ ДЛЯ СТУДЕНТА, вопросы к защите
  report.md        исходник отчёта (Markdown, синтаксис tools/md2docx/README.md)
  screenshots/     PNG, которые снимает студент (имена — из README.md)
  explain/         выводы запросов и EXPLAIN ANALYZE
  sql/             скрипты, нужные только лабе (схемы lab7, lab8)
  out/labNN.docx   готовый отчёт
```

Всё, что переходит в курсовую (таблицы, функции, триггеры, формы клиента), лежит в `db/` и `client/`, а не здесь.
Команды Claude Code: `/lab N` — выполнить лабу, `/lab-report N` — собрать отчёт (с ЛР 2).
