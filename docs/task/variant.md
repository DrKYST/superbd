> 16. Для автоматизации учета предоставления услуг связи фирмами-провайдерами Internet необходима информация о фирмах-провайдерах (название, тип собственности (государственный, частный, ЗАО, ОАО,…), адрес, телефон, год начала работы), о заключенных с ними договорах (абонент (ФИО или название предприятия, тип (частное лицо, школа, ВУЗ, предприятие,…), физический адрес, IP-адрес, телефон), дата подключения, стоимость подключения, стоимость 1 Мб информации) и о сеансах модемной связи (дата и время сеанса, количество Мб, тариф (бизнес-время — 100% оплата, вечерний тариф — скидка 20%, ночной тариф — скидка 50%,…)).

## Выбранный стек

- СУБД: PostgreSQL (обязательна по методичке).
- Клиент: десктопное приложение на Qt 6 / C++ (CMake), драйвер QPSQL.
- Отчёты по лабораторным и пояснительная записка: .docx по ГОСТ 7.32 / ГОСТ 2.105 (генерируются из Markdown скриптом `tools/md2docx`).

## Архитектурный принцип (зафиксирован студентом)

Вся бизнес-логика, авторизация, группы пользователей, разграничение доступа — на стороне БД.
Десктопное приложение — только тонкий клиент: подключается к PostgreSQL под учётной записью пользователя, вызывает функции схемы `api` и отображает результат.

## Порядок работы

Лабораторные выполняются строго по одной, по порядку. Отчёты оформляются начиная со второй лабораторной.
Результаты каждой лабы переносятся в соответствующий раздел пояснительной записки (см. `docs/roadmap.md`).
