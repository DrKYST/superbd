# Интерфейс клиента СуперБД — обязательный макет

Макет утверждён студентом 30.09.2026 (ЛР 4, решение D18). **Клиент на Qt делается строго по нему.** Этот файл — главный источник для всего, что касается внешнего вида и состава экранов; `docs/analysis/requirements.md` §8 и `.claude/rules/qt-client.md` его дополняют, но не отменяют.

## 1. Правила для Claude Code

1. Перед созданием или изменением любой формы клиента **открой её картинку** из `docs/ui/screens/` (инструмент Read показывает PNG) и исходник `docs/ui/mockup/<Экран>.dc.html`. Точные размеры, цвета, подписи, порядок колонок и данные-образцы — в исходнике (разметка + массивы в `renderVals()`), общий стиль — `docs/ui/mockup/common.css`.
2. Воспроизводи **всё видимое**: каркас окна, панели, тексты заголовков, кнопок, подписей полей и колонок (дословно, с двоеточиями и многоточиями), порядок элементов, группировку, жёлтую кнопку по умолчанию, итоговые строки, панель страниц. Не добавляй своих кнопок, иконок, цветов, скруглений, карточек, «плиток показателей» — их в макете нет.
3. Данные на картинках — образцы. В клиенте все значения приходят из функций `api.*`; счётчики «Текущих дел», итоги и расчёты клиент не вычисляет.
4. Если что-то нельзя сделать в Qt один в один — сделай ближайший штатный вариант и **запиши отличие** в `docs/ui/deviations.md` (экран, что в макете, что сделано, почему). Менять макет по своей инициативе нельзя; изменения — только по просьбе студента, и тогда сначала правится макет (`docs/ui/mockup/` + картинка), потом клиент.
5. После реализации экрана сними скриншот окна клиента и сравни с PNG макета; расхождения исправь или внеси в `deviations.md`.
6. Стиль — `docs/ui/superbd.qss` (перенос токенов макета в Qt Style Sheets); копируется в ресурсы клиента и подключается один раз на приложение. Цвета и размеры в коде форм не хардкодить.

## 3. Каркас главного окна (все экраны, кроме диалогов)

Окно 1440×900 (минимум 1280×800), сверху вниз:

| Элемент | Размер | Qt | Детали |
|---|---|---|---|
| Заголовок окна | системный | `setWindowTitle` | «СуперБД: Учёт услуг связи интернет-провайдеров (Ковалёва М. И., оператор, ООО «Степной провод»)» — ФИО и роль из `api.whoami()` |
| Панель разделов `#sectionBar` | высота 64 | `QWidget` + `QToolButton` (ToolButtonTextUnderIcon, checkable, autoExclusive), иконка 26 px, кнопка 112 px | разделы роли (табл. в §5); справа логин, «\|», ссылка «Выйти» |
| Панель навигации `#navPanel` | ширина 208 | `QWidget`/`QScrollArea`: заголовки групп (`QLabel`, жирный) + ссылки (`QPushButton` role=link, checkable) | группы и ссылки для каждого экрана — массив `nav` в исходнике |
| Вкладки открытых окон `#windowTabs` | высота 27 | `QTabBar` (closable) над `QStackedWidget` | первая всегда «Начальная страница»; активная — жирная на белом |
| Форма | остаток | страница в `QStackedWidget`, поля 14 px | заголовок `#formTitle` (19 px, #4d4d4d), под ним командная панель, дальше содержимое |
| Строка состояния | высота 22 | `QStatusBar` | «База: superbd на 127.0.0.1:5432», «Пользователь: login (группа)», справа дата |

Командная панель формы: `QHBoxLayout` кнопок высотой 24, первая — кнопка по умолчанию (жёлтая, жирная); разделители 1 px; справа поле «Поиск (Ctrl+F)» и «Еще ▾» (`QPushButton` с `QMenu`). Названия кнопок — как на картинке: «Создать», «Изменить», «Удалить», «Найти…», «Отменить поиск», «Записать и закрыть», «Записать», «Сформировать», «Сохранить в Excel…».

## 4. Элементы и их Qt-аналоги

| В макете | Qt |
|---|---|
| Таблица с сеткой, серыми заголовками, жёлтой текущей строкой | `QTableView` + модель (`PagedTableModel`), `verticalHeader()->hide()`, `setSelectionBehavior(SelectRows)`, `setSelectionMode(SingleSelection)`, `setShowGrid(true)`, высота строки 22; числа — выравнивание вправо; ID — в `Qt::UserRole`, не в колонках |
| Итоговая строка «Итого…» (жирная, серая) | последняя строка модели с ролью «итог» (жирный шрифт через `Qt::FontRole`, фон через `Qt::BackgroundRole`) или отдельная однострочная таблица-подвал; значения — из функции БД |
| Панель страниц `#pagerBar` | «Показывать по:» `QComboBox` 20/100/200 · `|◄ ◄` · «Страница» `QSpinBox` «из N» · `► ►|` · справа «Записи A–B из N» (N = `total_count`) |
| Группа «Отбор», «Расчёт…», «Пароль», «Параметры подключения» | `QGroupBox` |
| Поле с кнопкой выбора «…» | `QLineEdit` + `QToolButton#pickButton` вплотную (открывает форму выбора) |
| Поле даты с кнопкой «▦» | `QDateEdit` / `QDateTimeEdit` с `calendarPopup` |
| Подпись поля «Абонент:» | `QLabel` role=caption, форма — `QGridLayout` (подписи слева, как на картинке) |
| Зелёная отметка «✓ свободен…» | `QLabel` role=ok |
| Вкладки внутри формы договора | `QTabWidget` |
| Диаграмма отчёта | Qt Charts: `QStackedBarSeries` по месяцам, ось значений с сеткой, легенда справа в рамке; цвета рядов — `#4f81bd, #c0504d, #9bbb59, #8064a2, #bfbfbf` |
| Табличный документ отчёта | `QScrollArea` с белой областью: шапка (`QLabel` жирный + строки «Период…», «Отбор…»), диаграмма, `QTableView` с итогом |
| Дерево групп пользователей | `QTreeView`/`QTableView` с отступом подгрупп |
| Сетка «Временные зоны» | `QTableWidget` 2 × 24, ячейки — код тарифа, фон — цвет тарифа из списка |
| Блоки начальной страницы | `QFrame` role=block с заголовком `QLabel` role=blockTitle; ссылки — `QLabel` с `<a>` или `QPushButton` role=link |
| «Только просмотр» | тот же класс страницы, командные панели скрыты, к заголовку добавлено «(только просмотр)» серым |

## 5. Разделы по ролям (панель разделов)

| Роль (группа) | Разделы в порядке показа |
|---|---|
| Оператор (`grp_operator`) | Главное · Абоненты и договоры · Сеансы связи · Мой провайдер |
| Руководитель (`grp_manager`) | Главное · Абоненты и договоры · Сеансы связи · Статистика · Запросы · Мой провайдер |
| Главный аналитик (`grp_chief`) | Главное · Провайдеры · Абоненты и договоры · Сеансы связи · Статистика · Запросы |
| Администратор приложения (`grp_admin`) | Главное · Администрирование · Справочники · Провайдеры |
| Администратор БД (`grp_dba`, D26; макеты `ChangeLog`, `DbTables`, `DbConnections`) | Главное · Администрирование · База данных |

Раздел «Главное» открывает «Начальную страницу». Панель навигации каждого раздела — массив `nav` в исходнике экрана (у справочников все четыре справочника и провайдеры — в навигации администратора).

## 6. Стиль (токены)

Полный список — `docs/ui/mockup/common.css`, перенос в Qt — `docs/ui/superbd.qss`. Основное: шрифт Arial 13 px (10 pt); фон форм #ffffff; панель разделов #f5f5f5, активный раздел #fcefbf с рамкой #e0c255; ссылки #1a5ba6; заголовок формы 19 px #4d4d4d; кнопки — градиент #ffffff→#e8e8e8, рамка #b3b3b3, радиус 3; кнопка по умолчанию — #fff6cc→#f2cf4f, рамка #b8900c, жирная; поля — рамка #a6a6a6, радиус 2, высота 22; таблица — рамка #b8b8b8, сетка #e2e2e2, заголовок #fafafa→#e6e6e6, текущая строка #fbe7a1, итог #f2f2f2; строка состояния #efefef.

## 7. Проверка готовности экрана

- [ ] Каркас и размеры совпадают с PNG (панели, вкладки, строка состояния).
- [ ] Все подписи, кнопки и колонки — дословно как в макете, в том же порядке.
- [ ] Набор разделов, ссылок и кнопок соответствует роли; у руководителя «Абоненты» без командных панелей.
- [ ] Нет колонок и полей с ID.
- [ ] Пагинация 20/100/200 и «Записи A–B из N» работают через параметры `p_limit`/`p_offset` и `total_count`.
- [ ] Стиль только из `superbd.qss`.
- [ ] Скриншот окна сравнён с макетом; отличия — в `docs/ui/deviations.md`.

## 8. Как обновлять макет

Макет живёт на холсте Claude Design (ссылка в `labs/lab04/README.md`). После правок на холсте исходники и картинки в `docs/ui/` обновляются из него (попросить Claude в claude.ai), затем клиент подтягивается под новый макет.
