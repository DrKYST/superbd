# Исходники макета (Claude Design)

Файлы `.dc.html` — артборды холста ЛР 4. Вне Claude Design они не открываются как готовые страницы (нужна его среда выполнения), поэтому читайте их как текст: разметка — структура экрана, стили в `<helmet>` и `common.css` — точные размеры и цвета, массивы в `renderVals()` — подписи, колонки и данные-образцы. Как экран выглядит — `docs/ui/screens/<Экран>.png`.
