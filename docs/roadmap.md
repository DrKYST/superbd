# Дорожная карта: лабораторные → курсовая

## Что каждая лаба даёт курсовой

| ЛР | Результат в репозитории | Раздел ПЗ / пункт ТЗ |

| 3 Создание БД | `db/migrations/010_*.sql` … (схемы, домены, таблицы, индексы), `db/seed/` | ТЗ п.2, 4; 4.2; прил. Б |

## Порядок каждой лабы

1. `/lab N` — Claude читает задание из `docs/task/labs.md`, делает артефакты, проверяет их (SQL прогоняется на локальной БД).
2. Студент защищает лабу у преподавателя, вносит правки.
3. `/lab-report N` — сборка отчёта `.docx` (только ЛР 1 и ЛР 7; для остальных шаг пропускается). Скриншоты студент кладёт в `labs/labNN/screenshots/`.
4. Claude обновляет `docs/progress.md` и черновик раздела ПЗ в `coursework/pz/`.
