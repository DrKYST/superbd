# Учебники проекта (база знаний)

Текстовые копии учебников из проекта claude.ai «СуперБД», выгружены 2026-09-30 — та же база знаний, которой пользуется Claude в claude.ai. Формат — простой текст в `.md` без рисунков и таблиц-картинок; предназначены для поиска (`Grep`) и чтения фрагментов (`Read` с `offset`/`limit`), **не читать целиком** — файлы большие.

Методички кафедры (курсовой проект и лабораторные) сюда не входят: их PDF лежат в `docs/source/`, а проверенные расшифровки — в `docs/task/`.

Как пользоваться:
- Найти тему: `Grep` по ключевому слову в `docs/books/`, затем `Read` около найденной строки (±100 строк).
- Ссылаться в ПЗ — на книгу (автор, название, год), а не на этот файл; цитаты сверять по смыслу, номера страниц здесь не сохранились.
- Требования методички важнее учебников: при расхождении прав `docs/task/*.md`.
- Обновлять копии — только если студент заменит файлы в проекте claude.ai.
