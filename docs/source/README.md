# Исходные методички

- `metodichka-kursovoy.pdf` — методические рекомендации по курсовому проекту (ДонНТУ, 2024).
- `metodichka-laby.pdf` — методические указания к лабораторным работам (ДонНТУ, 2024).

Текстовый слой обоих PDF повреждён: кириллица закодирована нестандартным шрифтом, и при извлечении текста получается мусор вида «ɆɂɇɂɋɌȿɊɋɌȼɈ». Для работы используются проверенные расшифровки в `docs/task/`. Открывать PDF имеет смысл только чтобы посмотреть картинки (например, макеты интерфейса в ЛР 4), — страницы можно отрендерить в PNG: `pdftoppm -f 30 -l 34 -r 90 -png metodichka-laby.pdf lab4` (ЛР 4 — страницы 30–34 PDF).
