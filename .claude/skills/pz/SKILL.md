# Пояснительная записка

Структура и объёмы — `docs/task/coursework-requirements.md` §3 (таблица 2.1). Черновики разделов — `coursework/pz/NN-*.md`, порядок сборки — `coursework/pz/_order.txt`.

Если передан аргумент ($ARGUMENTS) — работай только с этим разделом; иначе — со всей запиской.

1. Для каждого раздела проверь по `docs/roadmap.md`, какие лабы и этапы его питают, и перенеси актуальное содержание из `labs/*/report.md`, `db/`, `client/`, `docs/analysis/`, `docs/decisions.md`. Отчёты лаб — основа, но текст ПЗ связный, без «в данной лабораторной работе».
2. Отметь в итоге разделы, для которых материала ещё нет (лаба не сделана) — не выдумывай содержимое.
3. Техническое задание (5 с.) — по приложению А методички: шапка, «Описание предметной области» = текст варианта, пункты 1–8, рекомендуемое содержание, график.
4. Реферат — по приложению В: считать фактическое число страниц, рисунков, таблиц, источников, приложений после сборки (по PDF); ключевые слова прописными.
5. Список литературы — ГОСТ Р 7.0.100; не менее источников из методички + документация PostgreSQL и Qt; ссылки `[N]` в тексте.
6. Сборка: склеить разделы по `_order.txt` в `coursework/pz/_pz.md` (фронтматтер `kind: pz`, `topic` из `reports/meta.yaml` → `coursework_topic`), затем:
   ```bash
   python ${CLAUDE_PROJECT_DIR}/tools/md2docx/md2docx.py coursework/pz/_pz.md -o coursework/out/pz.docx --kind pz
   ```
7. Проверка через PDF: объём 25–30 с. (без приложений), каждый раздел с новой страницы, сквозная нумерация. Напомнить студенту обновить оглавление (F9) и вставить ТЗ с подписями.
