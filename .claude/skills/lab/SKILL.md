# Выполнение лабораторной работы № $ARGUMENTS

## 1. Подготовка (не пропускать)
1. Прочитай задание и требования к отчёту ЛР $ARGUMENTS в `docs/task/labs.md`.
2. Прочитай указания для этой лабы в [lab-notes.md](lab-notes.md) (раздел «ЛР $ARGUMENTS»).
3. Проверь `docs/progress.md`: предыдущие лабы выполнены? Если нет — скажи студенту и спроси, продолжать ли.
4. Перечитай `docs/decisions.md` и связанные разделы `docs/analysis/*` — не противоречь принятым решениям. Новое решение → новая запись Dxx.
5. Если в задании есть развилка, которую нельзя решить по документам (например, вопрос к преподавателю), — задай один вопрос до начала работы.

## 2. Работа
- Артефакты, которые идут в курсовую, кладутся в основное дерево (`db/migrations/`, `db/seed/`, `db/tests/`, `client/`), а не в папку лабы. В `labs/labNN/` — только то, что нужно исключительно для лабы (схемы `lab7`/`lab8`, EXPLAIN-выводы, скриншоты, отчёт).
- Номер папки — две цифры: `labs/lab0$ARGUMENTS/` для ЛР 1–8.
- SQL прогоняй на локальной БД (`psql -v ON_ERROR_STOP=1`). Если БД недоступна — остановись и скажи, что нужно для подключения; «не проверено» писать явно.
- Для запросов сохраняй результат/EXPLAIN в `labs/labNN/explain/*.txt` — это материал для отчёта.

   - ожидаемые вопросы на защите (контрольные вопросы из методички + по нашему решению) с короткими ответами.
